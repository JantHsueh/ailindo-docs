本文介绍如何用「AI 灵动」的 API 密钥在 Trae 中配置自定义模型。如果还没有 API 密钥，请先阅读 [AI 灵动 新手指南](/zh/docs/usage-tutorial/ailindo-guide) 完成注册并获取密钥。

## 1. 登录Trae，找到设置 - 模型

![Trae 设置 - 模型](/assets/ailindo-guide/trae-settings.png)

## 2. 添加自定义模型

点击「**添加模型**」按钮

![Trae 添加模型](/assets/ailindo-guide/trae-add-model.png)

填写以下信息：

- 选择「**自定义配置**」
![Trae 自定义配置](/assets/ailindo-guide/trae-custom-name.png)

- **API 密钥**：粘贴你保存的密钥
- **模型名称**：填写模型名称

![Trae 填写模型信息](/assets/ailindo-guide/trae-model-info.png)

## 3. 测试验证

在 Trae 对话框选择模型对话，如正常回复，说明配置成功。

![Trae 对话](/assets/ailindo-guide/trae-chat.png)
